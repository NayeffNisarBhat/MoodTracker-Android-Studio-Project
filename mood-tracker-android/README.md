# Mood Tracker Android app

This project wraps the supplied HTML page in a native Android WebView. Mood entries remain on the device through the page's local storage.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync and install Android SDK Platform 35 if prompted.
3. Choose **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
4. Install the generated APK on an Android phone.
